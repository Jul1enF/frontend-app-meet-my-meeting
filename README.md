# Meeting Scheduler — Frontend (Mobile)

Mobile frontend application for a fully customizable meeting scheduling and calendar management system.

## 🚀 Overview

This application provides a flexible interface for:

- Managing calendars
- Creating and organizing meetings
- Displaying schedules and availability

The entire calendar and agenda system is built from scratch to allow full control over behavior and UI.

## ✨ Key Features

- Fully custom-built calendar system (no external UI libraries) :
    - Monthly calendar view (used as a date picker)
    - Weekly calendar view (used as a date picker)
- Fully custom-built agenda system (no external UI libraries) :
    - Daily agenda view
    - Create, update, and delete events
    - Designed for professionals to manage their full day schedule
- Dynamic display of available time slots
- Meeting creation and management
- Reusable components and hooks
- Centralized styles
- API handling with error management

## 🧱 Architecture

Built using a modular approach:

- Reusable UI components
- Custom hooks for logic separation
- Clean state management with Redux

## 📦 Tech Stack

- Expo / React Native
- TypeScript
- Redux
- Luxon (date management)

## 🎯 Goal

To provide a fully customizable mobile scheduling interface without relying on external calendar libraries, enabling complete control over both UI and business logic.
